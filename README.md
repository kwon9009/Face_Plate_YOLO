# AI 기반 개인정보 보호 민원 플랫폼 (Privacy-Safe Civil Platform)

## 📌 소개
이 프로젝트는 시민들이 특정 사건(예: 교통사고, 도난 등) 확인을 위해 CCTV나 블랙박스 영상을 요청할 때, 공공기관 같은 곳에서
영상 속 사람들의 얼굴이나 차량 번호판 같은 **민감한 개인정보를 AI가 자동으로 찾아 모자이크(블러) 처리해 주는 웹 서비스**입니다. 

기존에는 사람이 일일이 영상의 프레임을 확인하며 모자이크 처리를 해야 했지만, 이 플랫폼을 활용하면 AI 모델이 움직이는 객체를 자동으로 추적하여 가려줍니다. 이를 통해 누구나 사생활 침해 걱정 없이 빠르게 요청 영상을 받을 수 있습니다.

---

## ✨ 주요 기능

### 1. 🧑‍💻 사용자 (민원인) 기능
* **쉬운 민원 접수**: 이름, 이메일, 영상이 필요한 장소(주소)와 내용을 입력하여 간편하게 민원을 접수할 수 있습니다.
* **개인정보 동의서 제공**: 수집되는 정보와 서비스 목적을 명확히 안내하여 신뢰도를 높였습니다.
* **진행 상황 실시간 확인**: 내가 신청한 민원이 '대기 중'인지, '처리 중(AI 분석)'인지, '완료'되었는지 한눈에 확인할 수 있습니다.
* **결과물 다운로드**: 처리가 완료되면 안전하게 모자이크된 영상을 웹에서 바로 재생해 보거나 내 컴퓨터로 다운로드할 수 있습니다.

### 2. 👨‍⚖️ 관리자 (공무원/담당자) 기능
* **관리자 전용 대시보드**: 전체 민원 목록을 한곳에서 확인하고, 미처리/처리 완료 상태별로 필터링하여 업무를 효율적으로 관리합니다.
* **다중 영상 업로드**: 한 번의 민원에 대해 여러 개의 원본 영상을 동시에 업로드할 수 있습니다.
* **원클릭 AI 분석 및 제어**: 영상 업로드 후 '민원 처리 시작' 버튼만 누르면 AI가 알아서 분석을 시작합니다. 필요시 분석을 강제 중지할 수도 있습니다.

### 3. 🤖 AI 엔진 핵심 기능 (영상 처리 로직)
AI가 영상을 처리하는 과정을 쉽게 설명하면, 영상을 쪼갠 수많은 '사진(프레임)'에서 사물을 찾고 덧칠하는 과정입니다.
* **스마트 객체 탐지 (YOLOv8)**: 최신 AI 눈을 이용해 사람의 '얼굴'과 자동차의 '번호판', 그리고 '차량' 자체를 빠르고 정확하게 찾아냅니다.
* **안정적인 추적 및 예측**: 사람이 빠르게 움직이거나 번호판이 잠시 가려져도, AI가 이동 방향을 예측하여 모자이크가 끊기지 않도록 부드럽게 쫓아갑니다 (스무딩 및 예측 알고리즘 적용).
* **원거리 번호판 확대 분석**: 너무 멀리 있어서 잘 안 보이는 자동차는 AI가 스스로 화면을 확대(Zoom-in)하여 번호판을 찾아낸 뒤 모자이크 처리하는 꼼꼼함을 갖췄습니다.

## 🚀 사용 방법

### 🛠 기술 스택 (이 프로젝트를 만든 도구들)
* **Frontend (화면)**: React.js, CSS 
* **Backend (서버)**: FastAPI, Python 
* **Database (DB)**: MySQL
* **AI & Vision (영상 처리)**: YOLOv8, OpenCV
